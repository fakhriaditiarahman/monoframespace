## 2024-05-24 - React Rules of Hooks Violation inside `.map` with Framer Motion `useTransform`
**Learning:** Using Framer Motion hooks like `useTransform` directly inside an array `.map()` block inside a React component violates React's Rules of Hooks because the number of iterations (and thus hook calls) could theoretically change, breaking hook order stability. Furthermore, extracting static array creations and string splits outside of component bodies measurably reduces garbage collection pressure on high-frequency render components.
**Action:** Always extract loop iterations that require hook calls into their own separate functional components. Always extract static string splits and array declarations outside of functional component definitions to optimize memory usage and prevent unnecessary re-creations on every render.

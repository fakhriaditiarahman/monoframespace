## 2024-05-24 - Hooks in Loops for Scroll Animations
**Learning:** Calling `useTransform` inside a `.map()` callback to animate a list of items (like words in a text reveal) violates React's Rules of Hooks. While it might not crash if the list length is constant, it prevents proper hook tracking and increases the component's re-render footprint.
**Action:** Always extract loop items into separate functional components (e.g., `NarrativeWord`) when using hooks per item, ensuring valid hook order. Also, move static expensive computations (like `text.split(' ')`) outside the component to reduce garbage collection overhead on every scroll frame.
